# 연금 인출 세금 시뮬레이터 (똑재TV)

연금저축·IRP 속 돈을 **3개 바구니**(① 세액공제 받지 않은 원금 · ② 퇴직금 · ③ 세액공제 받은 원금+수익)로 나눠 넣으면,
꺼내는 방법별 세금과 **연 1,500만원 기준**을 지키는 인출 설계를 보여주는 단독 HTML 계산기입니다.

- 사이트: https://ttokjaetv.github.io/pension-tax-sim/
- 기준: 2026년 10월 현행 소득세법 (단순화 계산 · 세무 자문 아님)

## 파일 구조

```
index.html          ← 배포되는 완성본 (직접 고치지 말고 src를 고친 뒤 빌드)
src/engine.js       ← 세금 계산 엔진 (화면과 무관한 순수 계산)
src/template.html   ← 화면(HTML·CSS·UI 스크립트). /*__ENGINE__*/ 자리에 엔진이 들어감
src/build.py        ← template + engine → index.html
src/test.js         ← 엔진 단위 테스트 (기사·법정 예시와 손계산 대조)
```

## 고치는 순서

```bash
# 1) src/engine.js 또는 src/template.html 수정
cd src && node test.js        # ALL PASS 확인
cd .. && python src/build.py  # index.html 다시 만들기
# 2) GitHub Desktop에서 Commit → Push
```

## 계산 규칙 (2026년 기준)

| 항목 | 규칙 |
|---|---|
| 연금소득세 (확정기간형) | 55~69세 5.5%, 70~79세 4.4%, 80세 이상 3.3% (지방세 포함) |
| 종신형 | 2026년 신설 3.3% — 보험 상품 전용이라 계산 제외 |
| 1,500만원 기준 | ③ 연금수령분만 합산(①·② 제외), 모든 연금계좌·1월~12월·1인당. 이하이면 저율(3.3~5.5%) vs 종합과세 선택(소득세법 14조③9호 괄호), 초과 시 전액 종합과세 vs 16.5% 선택(64조의4) — 모두 유리한 쪽 자동 선택 |
| 퇴직금 연금수령 | 실제 수령연차 1~10년 70%, 11~20년 60%, 21년~ 50% 납부 |
| 연금수령한도 | 연초 평가액 ÷ (11 − 연차) × 120%, 11년차부터 제한 없음, 2013.3.1 이전 가입 6년차부터 |
| 한도 초과 | ② 퇴직소득세 100%, ③ 기타소득세 16.5% |
| 인출 순서 | 계좌마다 ① → ② → ③ (운용수익은 모두 ③) |
| 종합과세 | 연금소득공제(한도 900만) − 본인 기본공제 150만 − 경로우대공제 100만(70세 이상, 51조①1호), 기본세율 − 표준세액공제 7만원(0원 하한, 59조의4⑨), ×1.1. ③ 추가 세금 = (공적+③) − (공적만). 공적연금은 개시 나이부터 합산 |
| 퇴직소득세 간이 계산 | 근속연수공제 → 환산급여 → 환산급여공제 → 기본세율 × 근속연수/12 |

| 방법 | 총세금 | 실효세율 |
|---|---|---|

## 받는 방법 (STEP 02)

- 기간으로 / 금액으로
- **1,500 맞춤 – 순서대로**: ①② 쓰는 동안 원하는 금액, ③ 구간은 연 1,500만원 이하
- **1,500 맞춤 – 계좌 나누기**: 매년 ③에서 1,500만원 꽉 채우고 부족분을 ①→②에서 보충 (계좌가 나뉘어 있어야 실제로 가능). 퇴직금 감면 연차는 ②를 실제로 받은 해만 셈 (소득세법 제129조①5의2, 2026-10-20부터 · retire-drawdown과 같은 방식)

## 부부라면 · 건보료 체크 (2026-10-13 추가)

- **부부라면**: 배우자 ①②③·근속연수·나이 차이·공적연금을 넣으면, 같은 돈을 '부부가 각자' 가진 경우와 '한 사람 계좌에 다' 있는 경우를 같은 '계좌 나누기' 방식으로 비교 (원하는 금액을 계좌 잔액 비율로 나눔, 배우자가 55세 전이면 55세부터)
- **건보료 체크**: 은퇴 후 지역가입자 월 보험료(소득 + 재산 + 장기요양)와 피부양자 요건, 그리고 연금계좌 인출액을 일반계좌 배당으로 받았을 때와 비교
  - 2026년 건강보험료율 7.19%, 장기요양 0.9448%(소득 대비), 소득월액 하한 28만원·하한 보험료 20,160원, 소득 보험료 상한 월 4,591,740원
  - 지역: 공적연금 50%, 이자·배당 1인 연 1,000만원 초과 시 전액, 기타 100%. 재산 = 주택 과세표준(1주택 43/44/45%, 2주택 이상 60%) − 1억원 → 시행령 별표 4 등급 점수 × 211.5원
  - 피부양자: 소득(공적연금 100%) 2,000만원 이하 — 부부 함께 판정, 재산 과세표준 5.4억 이하 또는 9억 이하·소득 1,000만원 이하 — 각자 명의
  - 건강보험료(소득분·재산분 각각)와 장기요양보험료는 고지서처럼 10원 미만 버림 (2026-10-20부터, fin-income-tax·etf-vs-direct와 같은 방식)
  - 국내 직접 주식 배당이 종합과세되면 그로스업만큼 건보료 소득이 늘 수 있다는 안내만 표시(계산은 안 함 — 금융소득을 배당 종류별로 받지 않음)
  - 기준값은 금융소득종합과세·건보료 계산기(fin-income-tax)와 같음 · `engine.js`의 `NH`, `nhRegional`, `nhDependent`
