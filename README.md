# 연금 인출 세금 시뮬레이터 (똑재TV)

연금저축·IRP 속 돈을 **3개 바구니**(① 세액공제 안 받은 돈 · ② 퇴직금 · ③ 세액공제분+수익)로 나눠 넣으면,
꺼내는 방법별 세금과 **연 1,500만원 기준**을 지키는 인출 설계를 보여주는 단독 HTML 계산기입니다.

- 사이트: https://ttokjaetv.github.io/pension-tax-sim/
- 기준: 2026년 10월 현행 소득세법 (단순화 계산 · 세무 자문 아님)

## 파일 구조

```
index.html          ← 배포되는 완성본 (직접 고치지 말고 src를 고친 뒤 빌드)
src/engine.js       ← 세금 계산 엔진 (화면과 무관한 순수 계산)
src/template.html   ← 화면(HTML·CSS·UI 스크립트). /*__ENGINE__*/ 자리에 엔진이 들어감
src/build.py        ← template + engine → index.html
src/test.js         ← 엔진 단위 테스트 (기사·법정 예시와 손계산 대조)
```

## 고치는 순서

```bash
# 1) src/engine.js 또는 src/template.html 수정
cd src && node test.js        # ALL PASS 확인
cd .. && python src/build.py  # index.html 다시 만들기
# 2) GitHub Desktop에서 Commit → Push
```

## 계산 규칙 (2026년 기준)

| 항목 | 규칙 |
|---|---|
| 연금소득세 (확정기간형) | 55~69세 5.5%, 70~79세 4.4%, 80세 이상 3.3% (지방세 포함) |
| 종신형 | 2026년 신설 3.3% — 보험 상품 전용이라 계산 제외 |
| 1,500만원 기준 | ③ 연금수령분만 합산(①·② 제외), 모든 연금계좌·1월~12월·1인당. 이하이면 저율(3.3~5.5%) vs 종합과세 선택(소득세법 14조③9호 괄호), 초과 시 전액 종합과세 vs 16.5% 선택(64조의4) — 모두 유리한 쪽 자동 선택 |
| 퇴직금 연금수령 | 실제 수령연차 1~10년 70%, 11~20년 60%, 21년~ 50% 납부 |
| 연금수령한도 | 연초 평가액 ÷ (11 − 연차) × 120%, 11년차부터 제한 없음, 2013.3.1 이전 가입 6년차부터 |

| 퇴직소득세 간이 계산 | 근속연수공제 → 환산급여 → 환산급여공제 → 기본세율 × 근속연수/12 |

## 받는 방법 (STEP 02)

- 기간으로 / 금액으로
- **1,500 맞춤 – 순서대로**: ①② 쓰는 동안 원하는 금액, ③ 구간은 연 1,500만원 이하
- **1,500 맞춤 – 계좌 나눠 받기**: 매년 ③에서 1,500만원 꽉 채우고 부족분을 ①→②에서 보충 (계좌가 나뉘어 있어야 실제로 가능)

## 한계 (화면 하단에도 표기)

- 계좌를 하나로 합쳐 계산 (실제 수령한도·퇴직금 감면 연차는 계좌별)
- 매년 연초 같은 금액 인출, 운용수익률 고정, 100세까지만 계산
- 의료비·부득이한 사유 인출, 외국납부세액공제, 종합과세 시 기타 공제 미반영
